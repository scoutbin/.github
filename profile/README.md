# Scoutbin

Command-line tools written in Go, built on a shared core.

</div>

## Tools

- [scout](https://github.com/scoutbin/scout) - Codebase explore context done right
- [digest](https://github.com/scoutbin/digest) - Turn logs into readable facts
- [pin](https://github.com/scoutbin/pin) - Audit system behaviour in a lockfile

## Foundation

- [spine](https://github.com/scoutbin/spine) is the shared core of the tools. It is a Go module that uses only the standard library, plus reusable GitHub workflows that test and release them. Each tool gets version, info, check, and upgrade commands, cross-platform release archives (darwin, linux, windows; amd64, arm64) with checksums, and generated `install.sh` and `install.ps1` scripts. Pre-1.0.
- [homebrew-tap](https://github.com/scoutbin/homebrew-tap) is the shared Homebrew tap. Its formulae are generated by spine's release workflow.

## Install

Tools are available from GitHub Releases, install scripts, Homebrew, npm (`@scoutbin` scope), and a GitHub Action.

```sh
brew install scoutbin/tap/<tool>
npm i -g @scoutbin/<tool>
```
