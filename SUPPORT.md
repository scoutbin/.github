# Support

Get help through GitHub Issues on the repository for the tool you use. GitHub Issues is the only support channel. There is no support through Discussions, chat or email.

## What to include

In the commands below, `<tool>` is the name of the CLI tool, for example `pin`. The `version` and `info` commands apply to the CLI tools only.

- The output of `<tool> version` and `<tool> info`. Replace the executable path if it reveals private information.
- What you are trying to do.
- The commands or steps you ran, the result you expected and the result you got.
- The full error output, with secrets and personal data removed.

Search existing issues first. Your question may already have an answer.

## Response times

scoutbin is maintained on a best-effort basis. We answer issues when we can, and we do not guarantee response or resolution times.

## Security

Do not ask security questions in public issues. Report vulnerabilities as described in [SECURITY.md](https://github.com/scoutbin/.github/blob/main/SECURITY.md).
