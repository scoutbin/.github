# scoutbin/.github

Organisation-level repo for [scoutbin](https://github.com/scoutbin), a set of command-line tools written in Go and built on a shared core.

## Contents

- `profile/README.md` - the profile page shown on github.com/scoutbin.
- `assets/` - brand assets: avatar, and dark and light logos in PNG and SVG.
- `LICENSE` - Apache-2.0.

## Profile logos

The profile README loads its logos from `https://raw.githubusercontent.com/scoutbin/.github/main/assets/scoutbin-logo-{dark,light}.svg`. Renaming or moving these files breaks the profile page.

## Shared workflows

Reusable CI and release workflows live in [scoutbin/spine](https://github.com/scoutbin/spine), not in this repo.
